## 💡 How to Use These Projects

1. **Clone & Explore**: Each repository includes step-by-step setup instructions (`requirements.txt`, setup scripts, or database `.sql` dumps).
2. **Learn by Building**: Break down the code, extend features, and customize UI/backend logic.
3. **Academic Submission**: Cite properly and adapt the architectural diagrams and database schemas for your final year viva / capstone presentations.
